\doxysubsection{Detailed Description}
Головний контролер вебзастосунку «Кінопошук». Відповідає за відображення інтерфейсу користувача, виконання пошуку фільмів через OMDb API та кешування/\+збереження історії пошуків у локальній базі даних SQLite. 

Контролер використовує підхід Dependency Injection (DI) для отримання сервісу IOmdb\+Service та контексту бази даних App\+Db\+Context.
